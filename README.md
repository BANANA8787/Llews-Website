# My website
This is my personal website for the first PIXL trail. 
## Description
At the top it has a list of some of the languages I know. It also has a dark/light mode switch.
It then has two boxes side by side which have some info about me and some of my projects. 
At the bottom it has an interactive map powered by leaflet using open street map.
This map has markers for all the great walks I've been on and has pictures on them when you click on them
